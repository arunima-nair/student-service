
## Project Overview

The **Student Management System** API allows administrators to manage student records. It offers endpoints to:
- Add a new student.
- Retrieve a student's details by their ID.
- Update student information (name, grade, etc.).
- Delete a student by their ID.

## Technologies Used

- **Java** - Programming language(version 17)
- **Spring Boot** - Framework for building the API
- **Spring Web** - For building RESTful web services
- **Spring Data JPA** - For database interaction
- **H2 Database** - In-memory database for storing student records
- **Maven** - Dependency management and build tool
- **Spring Kafka** - For integrating Kafka messaging
- **Swagger** - For API documentation and testing
- **JUnit** - For unit testing
